# XYZ Programming Language

## Overview

XYZ is a lightweight interpreted programming language designed for cybersecurity education, systems programming, and compiler learning.

The language focuses on simplicity, security, and educational visualization while providing built-in cybersecurity utilities.

---

## Goals

- Easy to learn
- Secure by default
- Built-in cybersecurity library
- Educational interpreter
- Written entirely in C

---

## Features

- Simple syntax
- Interpreter
- Built-in hashing
- Base64
- Hex encoding
- File utilities
- Educational execution mode
